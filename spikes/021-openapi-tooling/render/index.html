Spike 021 — static OpenAPI rendering

Both pages below are single self-contained files with spec/openapi.utoipa.json inlined. They are regenerated by render/build.py from the emitted spec, so there is no third copy of the contract.

  • redoc.html — Redoc 2.5.3 standalone, cdn.redoc.ly
  • scalar.html — Scalar API Reference 1.66.1, cdn.jsdelivr.net

Both render with no server at all (verified over file:// in headless Chrome). The only network request either makes is the viewer bundle from its CDN — see NOTES.md §5 for what that costs and how to remove it.
