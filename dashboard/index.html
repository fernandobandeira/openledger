Reconciliation

  
openledger reconcile is the sweep — ten checks in one read-only transaction, exit 0 when every one is clean and exit 1 naming the breaks. It is a command an operator runs and schedules (ADR-0010), not a route, so there is nothing here to click: a check that must be able to say the book is wrong does not belong behind the surface the book is written through.


  
Amounts

  
Report amounts arrive as exact-integer decimal strings and are formatted here as strings — never parsed through a JavaScript number, which would silently round anything above 253. They are shown at two decimal places; hover any amount to see the exact minor units the wire carried.


  
What this page is

  
A development and internal-inspection affordance served by the openledger binary behind --dashboard, off by default. It is not part of the API: /dashboard is mounted outside the route table, appears in no OpenAPI document, and no conformance check knows it exists.
